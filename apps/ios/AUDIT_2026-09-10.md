# iPhone and Hook audit follow-up — September 10, 2026

Implemented in Hook 0.2.13 and iPhone build 34. Source commit `ea5eaedb`;
the subsequent packaging dependency update affects VS Code tooling only.

## Resolved

- History requests no longer disappear while a transcript poll is busy.
  A bounded queue handles WebSocket requests; the HTTP history route reads an
  older page directly. A shared sparse byte index avoids full JSONL re-parsing.
- The phone can page backward beyond its bounded message window. Metadata-only
  pages advance the cursor automatically; Latest restores recent history.
- Completion/abort variants and current activity override stale historical
  working states. TypeScript and Swift consume the same provider fixture.
- Draft persistence runs in an ordered actor. Attachment digests are cached;
  newer revisions supersede delayed writes. Immediate process relaunch retains
  the final text edit and images.
- Each web preview requires its own credential before opening a remote SSH
  channel. Forwarding is bound to one service; unrelated navigation leaves the
  privileged browser. CSS/scripts, redirects, uploads, and WebSockets pass.
- Custom-theme storage is versioned and preserves unreadable original data
  before accepting edits.
- Hono 4.13.5 and js-yaml 4.3.2 address the reported dependency advisories.
  `pnpm audit --json` reports zero vulnerabilities across 607 dependencies.
- Usage details state their per-response scope and distinguish cached input,
  uncached input, and included reasoning output. No estimated token counts.
- Agents and terminals work without GitHub; memory sign-in, expiry, and sign-out
  do not replace the root navigation or delete agent connection preferences.
- Default actions use Phren purple. Tool result envelopes unwrap for display;
  raw details remain available. Repository/tool patches share a compact diff
  renderer with semantic additions/deletions and line numbers when supplied.

## Remaining security dependency

Herdr 0.8.2 protocol 20 accepts pane/name targets for `agent.prompt` and
`agent.send_keys`, with no atomic expected-conversation parameter. The Hook
validates the full target tuple first, but replacing a pane's occupant between
validation and dispatch can redirect input. A second preflight is insufficient.
This task remains open; no unsupported field is sent and no atomic guarantee
is claimed. Herdr must enforce the expected identity at the input boundary.

## Validation

- CLI regression tests cover sparse indexing, growing/rotated transcripts,
  overlap with history requests, image bounds, exact targets, MCP compatibility,
  review promotion, and the exact slash-joined identifier secret-scan case.
- PhrenKit tests cover bounded history windows, lifecycle/usage fixtures, and
  ordered draft persistence. App tests cover account recovery and theme recovery.
- Simulator flows cover chat without GitHub, memory-setup dismissal, image and
  draft relaunch, Stop/Send, automatic history, token details, compact tool and
  repository diffs, and browser navigation.
- Real installed-Hook discovery and authenticated web forwarding pass through
  pinned SSH. Mac Mini `bridge doctor` passes on 0.2.13.
- A 603 MB local Codex log improved from 836 to 148 ms for initial reading,
  726 to 52 ms for older history, and 778 to 50 ms for reopening. These are
  computer-side measurements, not end-to-end physical iPhone latency.
- The signed app and widget, provisioning profile, HTTPS manifest, and downloaded
  build 34 IPA were verified. Physical phone installation requires the user to
  open the installer in Safari.

Machine deployment still needs Omarchy's accepted SSH key and the devcontainer's
host/user. App Store submission still needs review credentials, its Connect
record/upload, final demo screenshots, and the physical-device checklist.
